# Sitzplaner

Sitzpläne für Klassen anlegen, Tische frei anordnen und Schüler setzen.
Läuft im Browser am Rechner und auf dem iPad.

Dieses Repository enthält nur das Programm. Schülerdaten werden nie hochgeladen:
Sie bleiben im Speicher des Browsers auf dem jeweiligen Gerät und werden nur
über selbst erstellte Sicherungsdateien zwischen Geräten übertragen.
